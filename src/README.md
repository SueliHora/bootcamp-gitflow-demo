# Módulo 1 — Fundamentos de Git e Gitflow

Aplicação inicial em Node.js utilizada para praticar a criação de branches (`feature/*`), abertura de Pull Requests, revisão de código e padronização de commits.

## Estrutura

```text
src/
├── README.md
└── index.js      # Função multiplicar(valor1, valor2)
```

## Como Executar

A partir da raiz do repositório:

```bash
node src/index.js
```
